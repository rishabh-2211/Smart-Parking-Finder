Smart Parking Finder

Project Overview

Smart Parking Finder is a web-based parking management project developed using Node.js, Express.js, HTML, CSS and JavaScript.

The main objective is to help users find available parking locations easily and reduce the time spent searching for parking spaces.

Features

- View available parking locations.
- Display demo parking slot information.
- Select a parking location.
- Simple and user-friendly interface.
- Node.js and Express backend.

Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Development Tool: Visual Studio Code

Installation and Setup

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install dependencies:

"npm install"

4. Start the server:

"node index.js"

5. Open "http://localhost:3000" in your browser.

Project Status

This is an academic demonstration project. Parking availability and booking functionality currently use demo data. Real-time sensors, database integration and payment verification are planned for future development.
